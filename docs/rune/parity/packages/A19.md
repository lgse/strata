## Open

- A dragged folder never springs open over its own row in Columns, Icons or List. GTK arms the
  spring whatever the drop's validity (`src/ui/browser/clipboard.rs`, "Ignore drop validity so
  the source folder can spring open"); `policy::view_spring_target` reads the collection's
  `drop_over`, which a refused row clears. The sidebar springs a refused row already. No run
  covers it.
- A modifier released just before the drop is not remembered: GTK's `commit_override` falls
  back to the last modifier heard while hovering when none is held at the drop;
  `router::dropped` and `policy::commit` read only the modifiers held then. It matters for Ctrl,
  and for Shift onto another volume.
