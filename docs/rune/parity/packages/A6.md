## What dependents must know

- **An item's saved colour and icon** are `Preferences::item_color` and `item_icon`
  (`strata_desktop::settings`, `item_customization.rs`), keyed by the native path, with
  `set_item_colors`, `set_item_icon` and `clear_item_customization` beside them. Both
  interfaces read and write through them; a Rune part saves with `shell::saved(app).change(…)`.
- **The footer and the shortcut reference are this package's parts** (`footer.rs`,
  `shortcuts.rs`). The clipboard badge ([A12](A12.md)) and the 10X pill, marks, prompt and
  10xer sections ([A11](A11.md)) go into them by `contract` pull requests; each package has a
  note. A row of the reference comes from `shortcuts/contents.rs`, a copy of GTK's tables: a
  command added to the catalog's listed ones needs its row there too, or the coverage test
  fails.
- **`focusable` on an entry is read from its focus stop** (`Snapshot::is_focusable` in
  `crates/strata-app/src/qa/tree.rs`): an entry is focusable while the nearest element around
  it that takes focus names an active descendant. A view that makes each entry a focus stop
  of its own is read by the entry's own focus action, as before. A stop that names no active
  descendant (a list with no cursor) makes every entry read `false`, where GTK calls every
  row focusable; no scenario reaches that case.
- **A modal layer ends the shown view's pointer gestures** (`shell/grab.rs`). A new view
  registration sets `end_gestures` on its `View`, and ends there the gestures of every
  collection it shows; a part that answers `Holds::Modal` gets it with nothing to do.
- **Fifteen runs are now required that read what other packages built**: the Appearance
  popover's check and radio items ([A8](A8.md)), the empty folder's surface ([A2](A2.md)),
  the header's and the pane header's named buttons ([A3](A3.md), [A5](A5.md)), and the menus'
  rows and their order. A change to one of those that breaks the run is caught by
  `./scripts/qa-parity.sh A6`.
- **A menu row's hint comes from the catalog** (`Row::hint` in `menus.rs`, a `Shown`), labelled
  when the menu opens. A row added for a command gives the catalog's command, never a chord
  written out.
- **The window's later Escape and Enter are `window_keys.rs`'s** (registered by the menus'
  part): a part that answers Escape at an earlier stage (a popover, a dialog, the filter, a
  pending new item) keeps it from these, and a view that takes Escape or Return itself
  keeps it too. A key a view leaves comes here through the aliases.
- **Runs this package owns that another package's part unblocks** keep `package = "A6"`;
  each blocker names who flips it.
