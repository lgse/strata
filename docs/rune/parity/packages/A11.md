From [A10](A10.md) (2026-11-15, closing): **hooks for the 9 `tenxer` runs of `filter_results`
and `search_filter_sort`:**

- **10xer filter mode (`FilterState::set_tenxer`):** toggle `set_tenxer(true)` on A10's
  `FilterState` (`crates/strata-app/src/filter/`) while 10xer mode is active. With `tenxer` on,
  a `/` typed in the filter field stays literal instead of entering a folder (`queried`), the
  Enter target outline is suppressed, query edits keep the selection, and `filter::blur` keeps
  an open Columns filter across focus moves while 10xer hides chrome.
- **Footer rename on a filter result (`renamed-filter-result-keeps-focus`'s `tenxer` runs):**
  when 10xer's `rename ›` prompt submits a rename or move on a shown result, call
  `filter::follow_renamed(app, &from, to.as_ref())` once the browser accepts it (`None` when
  moved to another folder) and `filter::forget_renamed(app, &from, to.as_ref())` if it fails or
  is abandoned, as `crates/strata-app/src/rename.rs` does.
- **Result keys (`Stage::SearchResultKeys`):** `Filter::COMMANDS` registers
  `filter-result-keys` (`Outcome::Left` on keys other than Copy, Cut, Paste, Undo, Redo and
  Move to Trash while results hold focus). Wire 10xer's result-list navigation (`vim_arrow` in
  GTK's `search_result_keys`, `src/ui/window/keyboard.rs`) ahead of or beside it (`contract` on
  `filter/` or `commands`).
- **Sort and folder jump (`z`):** folder sort changes go through `Browser` (`set_sort`,
  `set_sort_key`, `set_sort_direction`, `set_name_comparison`), persisted via `folder_views`,
  and `palette::visits` already records every local folder a column finishes listing into
  `NavigationHistory::shared()`, which 10xer's `z` jump reads directly.
