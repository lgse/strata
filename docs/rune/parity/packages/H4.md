## Record

Dates are GitHub's, in UTC.

- **2026-11-14, PR_NUMBER.** A `contract` change to `crates/strata-app/src/qa/`: the QA
  mode's session host. `strata-rune --qa <directory>` with `STRATA_QA_WINDOW=1` opens the
  real window (`host::windowed`) and serves the runner's protocol from it. The backend is
  one, generic over its host (`qa/host.rs`): the offscreen host as before (`qa/staged.rs`),
  or the session host (`qa/session.rs`), which reads the tree from the frames the window
  draws, reaches the state through `AppHandle::update_if`, and sends input through Wayland's
  virtual keyboard and pointer. `mise run test-platform window::qa` drives it through a
  private sway: a key, a click, and a paste into the rename field from another process's
  clipboard. No run flipped: the runner and the image come next.

## What dependents must know

- The session host types on the US layout only: a `keymap` step for another layout fails
  there. A `resize` asks sway, which resizes a floating window; the runner's sway decides
  how the window is placed.
- On the session host `activate` clicks the element's middle through the pointer: an
  assistive client's click needs the accessibility bus.

## Notes from other packages

From [H1](H1.md) (2026-11-12), on how the ledger treats the session host:

- A `required` entry names its `host`, `offscreen` or `session`; a `pending` one may name
  the host its run will need. One does today: `keyboard-only-copy-paste/columns`
  ([A12](A12.md), `platform`, `host = "session"`).
- `./scripts/qa-parity.sh` refuses a selection that holds a `required` run on
  `host = "session"`: it exits 2 and names the runs. So H4 teaches the script the host in
  the same pull request that flips its first drag or clipboard run. Where to lift it:
  `report_selected` and `needs_session` in `scripts/qa_parity.py`, and the scripts' test
  `test_every_required_run_of_the_committed_ledger_runs_on_the_offscreen_host`.
- If H4 changes what `host` may hold, the rows of `tests/qa/parity_cases.toml` change first.

From [H2](H2.md): a `parallel` entry may name the host its twin runs on, and `session` is
refused there as for a `required` run, so H4 need not change the schema.
