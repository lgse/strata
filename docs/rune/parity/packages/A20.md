## What dependents must know

- **`--qa --portal` runs on the offscreen host only.** A portal run that needs a compositor (a foreign drag, `host = "session"`) waits for a session host for the portal, which A20 adds when the first such run can otherwise pass: [A19](A19.md)'s `chooser-sidebar-drops-survive-resize/list`.
- **A chooser's `App` is `App::new_chooser`,** with `app.browser.is_chooser_mode()` and `app.chooser.active` set. A part that must behave differently in a chooser asks those; a chooser's menus carry no custom-action or provider sections, as GTK's `chooser_context` menus do not.
- **The sidebar's grip is 1 pt wide.** A scenario or test that aimed at the sidebar's edge with a few points of slack now lands on the sidebar's blank space, which A9 routes to a marquee.
