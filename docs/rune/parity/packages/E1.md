- **Default directory folder chooser** (`src/ui/settings/general.rs:594`): General's `Default directory` row displays the abbreviated path and its `Reset` button without the `Choose` portal folder-picker button (portal chooser is [A20](A20.md)'s).

- **Actions, Integrations, Diagnostics, and interactive Update check** (`src/ui/settings/{actions,integrations,diagnostics,updates}.rs`): Actions, Integrations, and Diagnostics mount summary cards rather than GTK's custom-action editor, bundled-integration installer/catalog (`crate::file_providers::reload(app)` is ready once ported), and diagnostics runner; Updates mounts the `Check for updates automatically` toggle and `Release channel` menu with a read-only version label in place of the live GitHub check button.
- **About external URI links** (`src/ui/settings/about.rs`): About's `Website`, `Source code`, `Report an issue`, and `License` rows display their target URIs / license text rather than launching an external browser URI opener.

driver cannot drive windows**, and the owner ruled on 2026-11-19 that a driver that can is later
F or H work. It replays with no session bus (`bus: None` in `tests/qa/fuzz/replay.rs`), so a

another window (the Rune QA host keeps keys on the run's window, where GTK's new window takes
the X focus); and the observations are the run's window's (`sample.app`). With a bus and a
window-switch step, an alphabet could launch windows, open folders in new ones (Shift+Enter,
`open-in-window`) and act across them; A21 closed with its runs and window tests standing in
([`owner.md`](../owner.md#ruled)).
