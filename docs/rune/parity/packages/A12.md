## Notes from other packages

From [H1](H1.md): `keyboard-only-copy-paste/columns`, one of the slice's pending runs, is
this package's, `pending` on `platform` with `host = "session"`; `./scripts/qa-parity.sh`

From [A1](A1.md) (2026-11-12): **thumbnails do not wait for a running copy or move.** GTK
parks a file an operation holds and renders it on release (`HELD_FOR_OPERATION`,
`admit_after_release` in `src/ui/thumbnail/jobs.rs`). On the Rune side the render fails and
the tile keeps its icon until the row's key changes (the browser reads the finished file's
modification time and size) or the store's `retry_after` (30 s) passes. A run of this
package's that pastes images into a folder shown in Icons may see icons for up to 30 s where
GTK shows thumbnails at once. `A1.md`, "Open", has the detail.

From [A7](A7.md) (2026-11-12): **undo's replay asks no conflict prompt yet.** GTK prompts
when a move's undo or redo finds an item where it goes (`resolve_replay_collisions` in
`src/ui/browser/transfer/replay.rs`). `crates/strata-app/src/undo.rs` sorts the records as GTK
does and, where any collides, stops as the prompt's Cancel does: nothing moves and the entry
stays (`resume_move`). The prompt this package mounts for transfers is the one that goes
there, with GTK's Replace, Skip and Apply to All rules (`replay_prompt_visibility`,
`apply_replay_choice`); `undo.rs` is A7's, so the change is a note to A7 or a `contract`
pull request.
