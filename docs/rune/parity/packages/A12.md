## What dependents must know

- **Clipboard commands and query helpers (`crates/strata-app/src/clipboard.rs`):** `copy`, `cut`, `copy-path`, `copy-paths`, `copy-name`, and `copy-names` are live across all views. `clipboard::has_files(app)` reports whether file URIs are on the clipboard (including asynchronous verification of external Wayland offers so empty or comment-only URI lists do not light the badge), `clipboard::may_paste(app, location)` checks folder paste eligibility, and `clipboard::marks` / `clipboard::with_marks` supply `RowMarks { copied, cut }` to collection rows and tiles.
- **Footer clipboard badge (`crates/strata-app/src/footer.rs`):** C19's `Footer` receives `.clipboard(clipboard::has_files(app))` and `FooterLabels::{clipboard, clipboard_description}` matching GTK's `paste_label` (`"Files on clipboard"` and `"Press %{keys} to paste into a supported directory."`, or empty description when `PASTE` is unbound).
- **Conflict prompt (`crates/strata-app/src/conflict_dialog.rs`):** `ConflictDialog` (`Slot::Dialogs`, `Scope::Tab`) hosts GTK's `"File already exists"` prompt on C15's `StrataDialog` (`[Cancel, Skip?, Keep Both?, Merge?, Replace?]` plus `"Apply to All"`), shared by destination transfers (`transfer/collisions.rs`) and move undo/redo replays (`undo.rs`, `undo/replay.rs`). `conflict_dialog::prompt(app, prompt, on_choice)` and helpers `covered_by_answer`, `unreplaceable_explanation`, `compact_display_path`, and `shown_name` are `pub(crate)` for `A19` (`Drag and drop`) and other callers.
- **Paste, duplicate, New Folder with Selection, and transfer progress (`crates/strata-app/src/transfer.rs`, `new_item.rs`):** `paste` (`Ctrl+V`, folder menu), `duplicate` (`Ctrl+D` in Default map, `Stage::DirectCommands` when `tenxer_mode` is on, and entry menu), and `group` (`New Folder with Selection` row and `Ctrl+Alt+N` outside the preview drawer, falling back to plain `New Folder` when nothing is selected) run transfers, conflict resolution, same-folder numbered copies, and group-folder undo fusion (`UndoEntry::Group`) end-to-end, hosting C16's `DockView` in `Slot::Overlays` and `ProgressDialog` in `Slot::Dialogs`, and revealing placed items via `BrowserEvent::TransferReveal`.
- **Session-host QA clipboard steps (`crates/strata-app/src/qa/session/clipboard.rs`):** `clipboard_set` and `clipboard` are live on `host = "session"` via a private Wayland data-control connection, waiting for `Clipboard`'s offer and asynchronous file-URI check to settle and draw before `clipboard_set` returns.
- **Shared message dialog variants (`crates/strata-app/src/error_dialog.rs`):** `Error::partial_failure(message)` (`Completed with errors` / `Some items could not be processed`, `IconName::Close`, `Tone::Danger`) and `Error::information(title, summary, message)` (`IconName::Info`, `Tone::Accent`) are available alongside `Error::new`.
