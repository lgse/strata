## Notes from other packages

From [H1](H1.md): `preview-blank-click-keeps-selection/columns`, one of the slice's pending
runs, is this package's, since the plan gives the image viewer to neither A15 nor
[A16](A16.md). `quick_preview` is split by file and, in one case, by run: the PDF, model and
route files and the PDF variant of `preview-focus-ignores-file-commands` are A16's. Both are
defaults for the owner to confirm ([`owner.md`](../owner.md#h1-whole-corpus-ledger)).

From [A7](A7.md) (2026-11-13): **the delete keys must wait while the preview has focus.**
GTK's `confirms_delete` refuses Delete and Shift+Delete while the preview has focus
(`src/ui/window/keyboard/items.rs`), as `inline_editing` refuses rename. Rune's `trash` and
`delete` commands (`crates/strata-app/src/trash.rs`) and `rename` (`rename.rs`) guard only
on `!at.text()`, since nothing mounts a preview yet. Whoever mounts the preview adds it to
those guards, with `Situation::within`.
