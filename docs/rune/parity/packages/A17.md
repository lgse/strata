## What dependents must know

- **`properties` command and direct openers (`crates/strata-app/src/properties.rs`):** `"properties"` is live on `On::Focus` (`Alt+Return`), `On::Row` (entry and multi-selection menus), `On::Column` (folder background menu), and `On::Place` (sidebar place and pin context menus, wired via A4's `On::Place(Location)` in `sidebar/menu.rs`). `properties::show_entry`, `properties::show_location`, and `properties::show_selection` are `pub(crate)` for [A21](A21.md)'s D-Bus `org.freedesktop.FileManager1.ShowItemProperties`.
- **`StrataDialog` extensions (`crates/strata-components/src/dialog/action.rs`):** `StrataDialog::action_enabled(id, enabled)` disables an extra footer action (rendering it disabled and skipping Tab/arrow focus), and `StrataDialog::expose_subtitle(true)` exposes `<key>-subtitle` as a named accessible `label` inside the dialog alongside the dialog's `description`.
- **Sidebar pin status query (`crates/strata-app/src/sidebar.rs`):** `Sidebar::pin_state(&Location) -> PinState` (`Available`, `Pinned`, `Unavailable`) reports whether a folder is a built-in standard place, already in bookmarks, or eligible to pin.
