## What dependents must know

- **`Extract to` chooser handoff (`crates/strata-app/src/archive.rs`):** `archive::extract_to_chosen(app, entry, destination, tx)` is wired for [A20](A20.md)'s floating `Extract to` folder chooser. It records `pending_navigate`, starts `Browser::extract`, navigates to `destination` (or reveals in place when `destination` is already active) and selects the extracted item once `ArchiveCompleted` arrives, and clears `pending_navigate` on password prompt dismissal, operation failure, and cancellation (`archive_errors/abandoned-extract-to-no-hijack`).
- **External file-provider reload (`crates/strata-app/src/file_providers.rs`):** `file_providers::reload(app)` is wired for [A18](A18.md)'s Settings integrations pane; it stops running providers (retiring any provider that still owes an in-flight activation outcome), clears presented badges, and restarts discovery under `$XDG_CONFIG_HOME/strata/providers`.
- **Context-menu provider slot & nested submenu QA hierarchy (`crates/strata-app/src/menus.rs`, `crates/strata-app/src/qa/submenus.rs`):** `Menu::provider_slot` marks the section index where labelled provider sections splice after the open section (`3` when creation/group sections are shown on an entry, `1` otherwise, `2` on a folder background menu); downstream menu packages ([A14](A14.md), `Placement::SendTo`) that insert sections ahead of it should keep `provider_slot` aligned, and `qa/submenus.rs` already reparents open `rune-kit` `*-sub-menu` surfaces under their owning `menu` in `Snapshot`.
- **Archive preview & password prompt (`crates/strata-app/src/preview/archive.rs`, `crates/strata-components/src/viewers/archive/prompt.rs`):** `Viewer::Archive` (`"preview-archive"`) and `Viewer::ArchivePrompt` (`"preview-archive-prompt"`, `"preview-archive-prompt-field"`) are mounted inside `Preview`, `Preview::keyboard` reports `Holds::Field` while the password field has focus, `ArchivePrompt::on_field_key` forwards `ESCAPE_ANY_SHIFT` to `commands::on_key` (`Stage::PreviewPasswordEscape`), and `preview::show_entry` hands focus into the archive tree or password field (`archive_preview/tenxer-password-archive-keys/list` for [A11](A11.md)).

## Open

- **The archive password field reads differently in `app.preview`** (lgse/strata#2560, A13's
  part). GTK's `GtkPasswordEntry` holds an inner `GtkText`, and both are named by the
  placeholder, so GTK reads `Password` twice where Rune reads it once. Presenting that inner
  node on Rune would add a second field-like node under every secure field the QA backend
  targets, which the `archive_errors` and `archive_conflicts` dialogs' scenarios read. So
  `archives` never opens `encrypted.zip`'s preview, and the nine `archive_preview` runs hold
  the prompt. The coordinator confirmed on 2026-11-16 that `done` stands with this open, as
  A10 closed with #2441 open.

## Notes from other packages

- **`strata-rune` has a `rar` feature** (from [A1](A1.md), 2026-11-12): `strata-app` and `strata-rune` default to `rar`, forwarding `strata-core`, `strata-fs` and `strata-preview`'s, as the GTK application's default build does. Archive browsing on the Rune side has UnRAR unless built with `--no-default-features`.
- **The Compress dialog and starting compression live in `crates/strata-app/src/compress.rs`** (from [A6](A6.md), 2026-11-15): `start_compression` probes `archive_name_taken` off the UI thread (`strata_fs::adapters::probes::presence`), calls `Browser::compress` with `TransferConflict::FailIfExists` when the target path is free, and currently returns without overwriting when `taken` is true. Compression conflict prompts (`ask_to_replace_archive` for `Replace` / `Keep Both` / `Cancel`), `BrowserEvent::ArchiveStarted` progress and cancellation (`on_archive_started`), and undo for a replaced archive stay this package's (`A6.md`, item 7); `Compress::listen` already selects `select_name` in the destination folder on `BrowserEvent::ArchiveCompleted`.

- **The floating "Extract to" chooser calls `extract_to_chosen`** (from [A20](A20.md), 2026-11-17, [#2579](https://github.com/lgse/strata/pull/2579)): the `extract-to` row is registered in `archive.rs`'s commands and opens `crate::chooser::floating`, whose "Extract here" passes the folder chosen to `archive::extract_to_chosen`; the `dead_code` expectation on it is gone. `archive_errors/abandoned-extract-to-no-hijack/{columns-cancelled-password,columns-read-only-destination}` are `required` now, with `package = "A13"` kept; they passed three rounds on both targets.
