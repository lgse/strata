## What dependents must know

- **One settings store for the process.** `shell::saved(app)` is the window's way into it.
  A part that keeps its own copy of a setting, beyond what it reads at use, follows another
  window's change only if `shell::follow_another_window` makes it: add the call there.
  `Saved::share` gives a new window the store; `startup::load_settings` makes a new store, so
  two windows that each call it lose each other's saves (the portal host's choosers do).
- **A window's start.** `launch::Initial::Plain` is the only window that restores or persists
  `tabs.toml`. A later launch's window is `Fresh` (no argument) or `Argument`.
- **The QA mode with several windows.** Steps act on the run's window, root `window`; keys and
  the pointer go to it alone. A node of another window is read and activated in its own, so
  `within: {"other_window": "Strata"}` works for reads and `activate`. Focus between the
  offscreen windows is not modelled: the run's window keeps it.

## Open

- **GTK's argument card.** GTK mounts an argument that needs mounting, shows "Connecting to
  location…" with Cancel after a second, and "The requested location is unavailable" with
  Retry in the pane when GIO has no answer (`src/ui/window/open_argument.rs`). The Rune side
  opens such an argument as a location and lets the browser report it. No run covers it.
- **A forwarded launch's activation token** is not handed to its window yet, so on Wayland a
  later launch's window may not take the focus. Slice 2.
- **The session host serves no launch**: its QA mode does not claim the bus, and its backend
  reads one window. No session-host run launches. Slice 2.
- **Each window keeps its own per-folder-view store and thumbnail store.** Two windows
  converge on the folder views through the file, as two processes do. Slice 2 makes one of
  each for the process.
- **The pump goes through one window.** A view change in another window reaches its browser at
  that window's next `poll`, not before a dispatch the active window runs
  (`crates/strata-app/src/host/windowed.rs`, "Windows").

From [A8](A8.md) (2026-11-13), placed by the coordinator: **the window's presence for the
browser's revalidation is this package's.** GTK feeds `Browser::set_freshness` a
`FreshnessInput` whose `presence` follows the window: `Hidden` while it is unmapped,
suspended or minimized, `Focused` while it is active, `Visible` otherwise
(`presence_of` in `src/ui/presence.rs`), wired per window in
`src/ui/window/composition/tabs.rs` (`presence::follow`) to `BrowserView::set_presence`
(`src/ui/browser/view_modes.rs`), which also tells the path completion. The browser's checks
follow it (`regain_focus` and `follow_responsiveness` in
`crates/strata-fs/src/app/browser/freshness.rs`). The Rune side never calls
`set_freshness`, so the browser keeps its default, `Visible`, whatever the window does. The
input's `scope` is A8's; its power saver and `watch_network_folders` are [A18](A18.md)'s.

From [A4](A4.md) (2026-11-14, [#2474](https://github.com/lgse/strata/pull/2474)): **GTK's close guard holds on the window's own Close buttons
and on closing its last tab, not yet on a close the window manager asks for.** GTK refuses
every close request while a tab's browser has a file operation running, and says "File
operations are still active" (`close_guard::install` in `src/ui/window/composition/tabs.rs`).
On Rune, `shell::close_window` (`crates/strata-app/src/shell.rs`) does that for the header's
and the strip's Close and for Ctrl+W on the last tab. A close from the window manager (its
title bar, Alt+F4, the compositor) goes straight to Rune, whose `App::on_close` runs before
the window goes and cannot keep it (at `2a44156`): that half is finding
[#2473](https://github.com/lgse/strata/issues/2473) (`rune-gap`), for this package to draft
into the packet with the rest of the window's lifecycle, and to work around if it can.
GTK's application-wide guard for running jobs ("Background jobs are still active",
`src/ui/jobs.rs`) has no Rune side yet either.

From [A4](A4.md) (2026-11-15, [#2505](https://github.com/lgse/strata/pull/2505)): **only `launch::Initial::Plain` restores and persists `tabs.toml`**
