## What dependents must know

- **Undo and redo are commands `undo` and `redo`** (`crates/strata-app/src/undo.rs`), read at
  GTK's `text_input` stage outside a text field: Ctrl+Z, and Ctrl+Shift+Z or Ctrl+Y. A menu
  row or a button runs them by those ids. A key with nothing to replay is not taken.
- **A replay with an item in the way stops as the conflict prompt's Cancel does**, and its
  entry stays: GTK asks there (`resolve_replay_collisions` in
  `src/ui/browser/transfer/replay.rs`), and the prompt is [A12](A12.md)'s. The note in
  A12's file says where it plugs in.
- **Not shown:** the card GTK shows while a replay checks the disk, and the Trash undo's
  fly-out to the trash button.
- **New Folder and New File are commands `new-folder` and `new-file`**
  (`crates/strata-app/src/new_item.rs`): Ctrl+Shift+N at GTK's `file_commands` stage, and
  the menus' rows by their ids, in the row's or the folder's column. The editor opens on the
  created item through `rename::begin_new_item` with `Naming::NewItem`, and the typed name
  goes to `Browser::name_new_item` (a path, to `place_entry` with `new_item`), so one undo
  trashes the item under its new name. Escape before the editor opens gives up the naming
  (`new-item-cancel`, at `inline_editing`).
- **A rename the browser fails shows GTK's "Unable to rename item" dialog**
  (`crates/strata-app/src/rename_failed.rs`, which calls the shared error dialog,
  `error_dialog.rs`, A5's [#2299](https://github.com/lgse/strata/pull/2299)), the first part in the `Dialogs` slot: C15's
  `StrataDialog` with the browser's message, one Close button that has the keyboard, and
  `Holds::Modal { field: false }` while it is open. The editor no longer opens again with the
  message. A rename Tab moved on from takes the cursor back and closes the neighbour's editor
  first, as GTK's `fail_pending_rename_from_browser` does. GTK shows the same dialog for other
  failures; a package that needs it for another command can make it the window's.
- **Deleting is the commands `trash` and `delete`** (`crates/strata-app/src/trash.rs`):
  Delete and Shift+Delete in the default map at GTK's `dismissal` stage, outside a text
  field, and the entry menu's Move to Trash and Permanently Delete rows. A permanent delete,
  Delete in the Trash, and a trash where the location deletes but cannot trash ask first in
  GTK's confirmation (`trash/dialog.rs`, in the `Dialogs` slot, `Holds::Modal` while open).
  A trash that some items fail for want of Trash support asks to delete those for good.
  "Completed with errors", for every other partial failure, waits for the window's error
  dialog (A5).
- **A new item does not clear the column's filter first**, as GTK's `begin_new_entry` does:
  the filter is [A10](A10.md)'s, and the note in its file says where it goes.
