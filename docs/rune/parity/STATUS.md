# Parity status

The state of each work package of [the parity plan](README.md), one row each, grouped by
wave. The states are `not started`, `in progress`, `done` and `held`. The package files under
[`packages/`](packages/) are the source: each says its state, why it is held, what it has
delivered and what is open, and a package's agent edits only its own. **Package pull
requests do not edit this file.** Whoever coordinates (the owner, or the session the owner
delegates coordination to) brings it up to date from the package files, in small docs-only
pull requests of its own. Questions for the owner and the owner's rulings are in
[`owner.md`](owner.md), and the findings in [`findings.md`](findings.md).

Each package was tracked in a GitHub issue until 2026-11-12, when the issues were closed and
tracking moved here. The issues stay as an archive: each package file links its own.
