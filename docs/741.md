## What changed

`modified_date_at` used to count days as elapsed microseconds divided by 24 hours. A file from Sunday 23:30 was labelled `Yesterday` on Tuesday evening, and a file seven calendar days old could show today’s weekday.

The fix introduces `calendar_day_difference`: local civil dates of the two timestamps (midnight in each value’s timezone), then `(span + 12h) / 24h` so a DST-shortened or lengthened day still counts as one. Label buckets are unchanged:

| Local calendar `day_diff` | Label |
| --- | --- |
| 0 (same date) | `just now` / `Nm ago` / `Nh ago` from elapsed time |
| 1 | `Yesterday, HH:MM` |
| 2–6 | weekday name and time (`%A %H:%M`) |
| 7+ same year | `Mon D, HH:MM` (`%b %-d, %H:%M`) |
| 7+ other year | `Mon D, YYYY` |
| future mtime | `%Y-%m-%d %H:%M` |

`Yesterday` is hardcoded English. Weekday and month names come from `glib` format strings and follow `LC_TIME`. Pin `LC_ALL=C.UTF-8` unless a case says otherwise, so expected strings match this sheet.

Call sites that show the relative string: List **Modified** column, Columns/List live row updates, quick preview **MODIFIED**, and the Properties **MODIFIED** row *before* GIO refresh. Properties then overwrites that row with an absolute `%Y-%m-%d %H:%M` stamp (pre-existing; see 741-12).

### Expected-label helper

With `LC_ALL=C.UTF-8` and the tester’s local zone:

```bash
# $1 = path; prints civil date of mtime and of now
python3 - <<'PY'
import os, datetime, pathlib, sys
path = pathlib.Path(os.environ["WORKDIR"]) / "files"
now = datetime.datetime.now().replace(second=0, microsecond=0)
print("now", now.isoformat(sep=" "))
for p in sorted(path.iterdir()):
    m = datetime.datetime.fromtimestamp(p.stat().st_mtime).replace(second=0, microsecond=0)
    day_diff = (now.date() - m.date()).days
    print(f"{p.name}\tmtime={m.isoformat(sep=' ')}\tday_diff={day_diff}")
PY
```

Map `day_diff` through the table in “What changed”. Time-of-day in the label is the file’s local `%H:%M` (24-hour, zero-padded hours). Month day uses `%-d` (no leading zero): `Sep 1, 23:30` not `Sep 01`.

### 741-14 — DST midnight spans (23h spring, 25h fall)

**Purpose:** Midnights on either side of a DST change are 23 or 25 hours apart. The implementation rounds with +12h so those gaps still count as one calendar day. Live GUI cannot hit US 2026 DST from a September wall clock without faking time; this case probes GLib the same way the formatter does.

**Fixture setup:** No Strata window. Disposable shell only. Requires `python3` with `gi.repository.GLib` (PyGObject). If import fails, mark **BLOCKED**.

**Steps:**

1. Run:

```bash
python3 - <<'PY'
from gi.repository import GLib

US = 43_200_000_000
DAY = 86_400_000_000

def midnight(dt):
    y, m, d = dt.get_year(), dt.get_month(), dt.get_day_of_month()
    return GLib.DateTime.new(dt.get_timezone(), y, m, d, 0, 0, 0.0)

def calendar_day_difference(modified, now):
    span = midnight(now).difference(midnight(modified))
    return (span + US) // DAY

def old_24h(modified, now):
    return now.difference(modified) // DAY

tz = GLib.TimeZone.new("America/New_York")
spring_mod = GLib.DateTime.new(tz, 2026, 3, 8, 23, 30, 0.0)
spring_now = GLib.DateTime.new(tz, 2026, 3, 9, 23, 0, 0.0)
fall_mod = GLib.DateTime.new(tz, 2026, 11, 1, 23, 30, 0.0)
fall_now = GLib.DateTime.new(tz, 2026, 11, 2, 12, 0, 0.0)
sat_mod = GLib.DateTime.new(tz, 2026, 10, 31, 23, 30, 0.0)

def show(label, modified, now):
    span_h = midnight(now).difference(midnight(modified)) / 3_600_000_000
    print(
        f"{label}: midnight_hours={span_h:.0f} "
        f"calendar={calendar_day_difference(modified, now)} "
        f"old24={old_24h(modified, now)}"
    )

show("NY spring Sun 23:30 -> Mon 23:00", spring_mod, spring_now)
show("NY fall Sun 23:30 -> Mon 12:00", fall_mod, fall_now)
show("NY fall Sat 23:30 -> Mon 12:00", sat_mod, fall_now)
PY
```

2. Confirm GLib constructed 00:00 on 2026-03-08, 2026-03-09, 2026-11-01, and 2026-11-02 (if `DateTime.new` returned `None` for a midnight, record **BLOCKED** and the date).

**Expected result:**

| Probe | `midnight_hours` | `calendar` | `old24` |
| --- | --- | --- | --- |
| Spring Sun 23:30 → Mon 23:00 | 23 | 1 | 0 |
| Fall Sun 23:30 → Mon 12:00 | 25 | 1 | 0 |
| Fall Sat 23:30 → Mon 12:00 | — | 2 | 1 |

`calendar == 1` for the first two rows is the DST rounding this PR claims. `old24 == 0` is what 24-hour windows would do (same-day hours-ago). Fail if `calendar` is 0 or 2 for a single civil day across the transition.

### 741-18 — Year boundary Yesterday (GLib probe)
